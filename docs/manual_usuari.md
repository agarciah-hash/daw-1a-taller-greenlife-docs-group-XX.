# Manual d'usuari - GreenLife


## Introducció
Aquest manual explica com utilitzar l'aplicació GreenLife.


## Requisits previs
- Disposar d'un compte d'usuari
- Tenir connexió a Internet


## Funcionalitats principals
- Registre de consum elèctric
- Visualització de gràfics
- Alertes de consum excessiu
